# WP PDF AcroForm Filler

Upload a PDF and fill AcroForm fields using pdf-lib.

## Installation and use

Place the `wp-pdf-acroform-filler` directory in `wp-content/plugins/` and activate **WP PDF AcroForm Filler** from the WordPress Plugins screen.

Add `[pdf_acroform_filler]` to a page to display the PDF form interface.
